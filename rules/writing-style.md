# Writing Style

- Brief and direct. Lead with the answer.
- Never use the word "erm".
- Never use em dashes or double em dashes in prose, code comments, or documents. Use commas, colons, or periods.
- Plain words. No hype. Numbers over adjectives.
- Mark unverified claims `VERIFY`. Cite primary sources with dates once verified.
- Tables for comparisons, bullets for lists, prose for reasoning.
